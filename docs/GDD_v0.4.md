## 1. プロジェクト概要

### キャッチコピー
**「間口は広く、深みは本物。」**

### ジャンル
経営シミュレーション × 育成RPG（PWAアプリ）

### ターゲットユーザー
- メイン：相撲にハマり始めた若い層（20〜30代）
- サブ：たまに本場所を見る主婦層
- 隠れターゲット：相撲ガチ勢も唸らせるリアリティを担保

### 参考タイトル
- **カイロソフト系**：箱育て・経営の手触り・ゆるいゲームオーバー設計
- **パワプロ サクセスモード**：キャラへの愛着・育成の達成感・特別演出

---

## 2. ゲームのコアコンセプト

### プレイヤーの立場
**親方**として相撲部屋を経営する。

### 大目標
**部屋から横綱を一人輩出する。**

### 感情設計（二層構造）
```
上層：部屋への誇り（経営・名声・歴史）
下層：力士への愛着（個性・成長・ドラマ）
　　　↕ 互いに強化し合う
```

---

## 3. ゲームサイクル

### マクロサイクル（1年 = 6場所）
```
場所間フェーズ → 本場所（15日）→ 結果・成長 → 場所間フェーズ → …
```

### 場所間フェーズ（メインの操作時間）
イベント単位で指示を出す。毎日操作は不要。

| イベント種別 | 頻度 | 対象 |
|------------|------|------|
| 稽古 | 毎場所間・複数回 | 全力士 |
| 後援会挨拶 | 不定期 | 親方 |
| 地域イベント | 不定期 | 全力士 |
| 出稽古 | 不定期 | 関取以上 |
| 巡業 | 不定期 | 関取以上 |
| スカウト・入門対応 | 不定期 | 親方 |
| 部屋設備の整備 | 任意 | 親方 |

### 本場所フェーズ

| 番付 | 取組数 | 備考 |
|------|--------|------|
| 十両以上 | 15番（毎日） | 関取 |
| 幕下以下 | 7番（奇数日のみ） | 力士 |

### ハイブリッド操作システム

| モード | 内容 |
|--------|------|
| 個別指示 | 注目力士に細かく指示 |
| 自動管理 | 未指示の力士は設定方針で自動行動 |
| 一括指示 | 全力士に同じ方針を適用 |

## 5. 能力値設計

### 表の能力値（0〜100）

| 能力値 | 説明 | 主な影響 |
|--------|------|---------|
| 体力 | スタミナ・場所後半の粘り | 連日取組のパフォーマンス維持 |
| 筋力 | 当たりの強さ・押し力 | 押し相撲・ぶつかり合いの優劣 |
| 技 | 決まり手の引き出し・器用さ | 技巧派スタイルの発揮度 |
| 精神 | 勝負強さ・土俵際の粘り | 大一番・逆転の発生率 |
| 体重 | 当たりの重さ（別軸管理） | 適正体重で最大効果 |

### 体重の適正設計

| スタイル × 体格 | 適正体重の傾向 |
|----------------|--------------|
| 押し相撲 × 大型 | 重いほど有利・適正が高い |
| 技巧派 × 小兵 | 軽めが最適・重すぎると技が出にくい |
| 四つ相撲 × 中型 | バランス型・中程度の適正 |

### 隠れ数値

| 隠れ数値 | 説明 | 改善方法 | プレイヤーへの開示 |
|----------|------|---------|-----------------|
| 怪我耐性 | 怪我の発生確率 | 筋力・体力を上げると自動改善 | テキストでほのめかす程度 |

### 成長カーブ
- 年齢と伸びしろランク（S/A/B/C/D）の2軸で成長速度が変わる
- 若いほど伸びやすく、30代以降は鈍化
- 能力値ごとに力士固有の「伸びやすい能力」が存在する

## 6. 力士の個性設計

### 体格軸

| 体格 | 目安体重 | 特徴 |
|------|----------|------|
| 小兵 | 〜100kg | 速さ・技で勝負。番狂わせが起きやすい |
| 中型 | 100〜140kg | バランス型。成長の幅が広い |
| 大型 | 140〜180kg | パワー・当たりが強い。持久力が課題 |
| 超重量級 | 180kg〜 | 圧倒的な重さ。押し相撲では無双 |

### 相撲スタイル軸

| スタイル | 説明 |
|----------|------|
| 押し相撲 | 突き・押しで一気に勝負。スタミナ消費大 |
| 四つ相撲 | 組んでから発揮。技の種類が多い |
| 技巧派 | 決まり手の引き出しが多い。体格差を覆せる |
| 精神力型 | 土俵際の粘り・勝負強さが突出 |

### スカウト・出会いの設計

**出会い時に見える情報**
- 現在の能力値（体力・筋力・技・精神）
- 体格・スタイル
- 出自（出身都道府県／国籍・学歴・相撲経験の有無）
- 伸びしろランク（S/A/B/C/D）

**入門後に判明する情報**
- 伸びしろの中身（どの能力が特に伸びるか）
- 隠れた才能（特定条件で開花するボーナス）
- 性格・取り組み姿勢

**弟子候補の生成方式**
- 完全ランダム生成（固定キャラなし）
- 四股名は日本語の本物らしい組み合わせで生成
- 出身傾向がリアルに沿う（例：モンゴル出身は四つ相撲が多い）
- 稀に「逸材」フラグが立つ

### ドラマ設計

| タイプ | タイミング | 対象 |
|--------|-----------|------|
| 入門イベント | 入門時1回のみ | 全員 |
| 成長ドラマ | 能力・状況連動でランダム発生 | 一部 |

### 引退システム

**自動引退トリガー**
- 年齢30歳以上、かつ負け越し6場所連続 → 「引退勧告」告知（猶予あり）

**任意引退**
- 各力士の詳細ページに引退ボタンを設置

**引退後**
- 部屋のOBとして永久記録に残る
- 引退時は特別演出あり

## 7. 稽古システム

### プレイヤーが選ぶアクション

| 稽古種別 | 主な効果 | 怪我リスク | 消耗度 |
|---------|---------|----------|--------|
| 基礎稽古 | 体力・筋力の基礎強化 | 低 | 低 |
| 申し合い稽古 | 技・精神強化 | 中 | 中 |
| ぶつかり稽古 | 筋力・精神の大幅強化 | 高 | 高 |
| 自主トレ | 任意の能力値を選んで強化 | 低 | 低 |

### 方針設定で自動管理

| 食事方針 | 効果 |
|---------|------|
| 増量食 | 体重増加・筋力強化。機動力リスクあり |
| 標準食 | バランス型・現状維持 |
| 絞り食 | 体重減少・機動力維持。筋力が伸びにくい |

- 睡眠は部屋の設備レベルに連動して自動管理
- ちゃんこ場レベルが上がると食事方針の効果が向上

## 8. 部屋経営システム

### 経営3軸の重み

```
【メイン】育成
　└ 弟子との稽古・方針・関係性
【サブ】スカウト
　└ 部屋の名声が上がると良い弟子が来やすくなる
【サポート】後援会
　└ 資金力が育成環境を支える
```

### 資金システム

**収入**
- 後援会からの会費・寄付（メイン収入）
- 懸賞金（関取の取組）
- 協会からの交付金（番付連動）
- 後援者からのお祝い金（優勝・昇進イベント時）

**支出**
- 食費（ちゃんこ）
- 稽古場・設備の維持費
- 設備のアップグレード費用
- スカウト活動費
- 医療費（怪我時）

### ゲームオーバー設計
- **ゲームオーバーなし**
- 常に最低1人の弟子が在籍することを保証

---

## 9. 対戦相手（CPU力士）システム

- 番付連動型のランダム生成
- 番付ごとに再出現率を設定
  - 序ノ口〜幕下：同じ相手と複数回当たりやすい
  - 十両〜幕内：顔ぶれが比較的固定される
- 過去対戦記録を保存・閲覧可能
- 対戦数が重なると「因縁の相手」テキストが出る

## 13. ビジュアル方針

- **スタイル**：パワプロ的なコミカルデフォルメ（2〜3頭身）
- **技術**：ドット絵またはAI生成ベース（技術検討中）
- **愛着設計のための差別化要素**
  - 体格による体型の違い
  - 番付による装い変化（まわしの色・横綱の綱・化粧まわし・髷）
  - 表情・ポーズのバリエーション

- 自動保存・1スロットのみ
- 保存先：localStorage（PWA標準）

## 16. 画面設計

### 画面一覧と動線

```
ホーム画面
　├ 新規開始 → チュートリアル → 部屋ダッシュボード
　├ 続きから → 部屋ダッシュボード
　└ 初期化（確認ダイアログあり）

部屋ダッシュボード（ゲームの起点）
　├ 力士一覧 → 力士詳細
　├ スカウト画面
　├ 設備管理画面
　├ 後援会管理画面
　├ 部屋の歴史・記録画面
　└ 場所へ出陣
　　　└ 場所間イベント画面
　　　　　└ 本場所画面
　　　　　　　└ 場所結果サマリー画面
　　　　　　　　　└ 部屋ダッシュボード
```

### 各画面の表示内容

#### ホーム画面
- タイトルロゴ
- 新規開始・続きから・初期化ボタン

#### 部屋ダッシュボード
**メインビジュアル**：在籍力士の顔ぶれ

**部屋ステータス**
- 部屋の名声レベル
- 資金残高
- 後援会規模
- 設備レベル

**力士ステータス**
- 在籍力士数
- 関取の人数
- 現在の最上位力士の番付
- 次の場所（〇年〇月・場所名）

#### 力士詳細画面（スクロール1画面）
- 力士のビジュアル（体格・番付に応じた見た目）
- 四股名・年齢・出自
- 現在の番付・最高位
- 相撲スタイル・体格
- 能力値5つ（体力・筋力・技・精神・体重）＋伸びしろランク
- 通算成績（勝敗数）
- 今場所の成績
- 食事方針の設定
- 稽古指示
- 過去対戦記録
- 引退ボタン

#### スカウト画面
- 候補力士一覧（能力値・体格・スタイル・出自・伸びしろランク）
- 入門交渉ボタン
- スカウトに出向くボタン（活動費消費・逸材出現率アップ）

#### 設備管理画面
- 設備一覧（ちゃんこ場・稽古場・宿舎など）
- 現在のレベル・アップグレード費用・効果説明

#### 後援会管理画面
- 後援会規模・現在の収入
- 関係強化イベントの一覧

#### 部屋の歴史・記録画面
- 歴代力士一覧（OB含む）
- 場所ごとの成績推移
- 部屋の通算記録

#### 場所間イベント画面
- 発生イベントの内容表示
- プレイヤーの選択・指示入力

#### 本場所画面
- 対戦カード（自力士 vs 相手力士）
- 両力士の現在番付・簡易ステータス
- その相手との過去対戦成績
- 取組実行ボタン（1番ずつ進める）
- 取組結果テキスト＋決まり手
- その日の他力士の結果
- 星取表（自力士の成績＋相手力士の今場所成績）

#### 場所結果サマリー画面
- 全力士の今場所成績
- 番付変動の確認
- 成長した能力値の表示
- 次の場所への導線
